📅 Calendario Públicas Cliente Profesional

Cómo funciona el calendarioEl cliente fija día + hora + turnos desde el chat; el backend valida que el profesional no tenga otro trabajo en ese horario.

Paso 1El cliente acepta una oferta → el trabajo queda Asignado y se abre el chat.
Paso 2En el chat aparece "Definir fecha del trabajo". Toca y elige día, hora y duración (1 o 2 turnos).
Paso 3Se guarda la fecha y se envía un mensaje automático al chat con la fecha acordada.
Paso 4El profesional ve el trabajo en su Agenda, con hora y cliente.
Reglas del calendario: 1 turno = 90 minutos (DURACION_TURNO_MIN = 90). El cliente puede elegir 1 o 2 turnos. El trabajo se considera "agendado" cuando está Asignado + tiene fecha (no hay estado nuevo). Si el profesional ya tiene otro trabajo asignado que se solapa con ese horario, el backend responde 409 y no se guarda. El cliente no tiene restricción de superposición (puede tener trabajos seguidos).
